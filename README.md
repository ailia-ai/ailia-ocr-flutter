## About ailia OCR

ailia OCR is a C++ implementation of PaddleOCR running on the ailia SDK. It detects text regions in an image and recognizes the text. The ailia SDK (ailia package) must be available at runtime.

## Usage

Add the package to `pubspec.yaml` as a git dependency.

```yaml
dependencies:
  ailia_ocr:
    git:
      url: https://github.com/ailia-ai/ailia-ocr-flutter.git
      ref: v1.2.1
```

`ailiaOcrFFI` is the low level binding generated by ffigen. `openAiliaOcrLibrary()`
opens the native library bundled with the application.

```dart
import 'package:ailia_ocr/ailia_ocr.dart';
import 'package:ailia_ocr/ailia_ocr_library.dart';

final ailiaOcrFFI ffi = ailiaOcrFFI(openAiliaOcrLibrary());
```

## Native libraries

| Platform | File |
|----------|------|
| macOS | `macos/libailia_ocr.dylib` (universal) |
| iOS | `ios/libailia_ocr.a` |
| Windows | `windows/x64/ailia_ocr.dll`, `windows/arm64/ailia_ocr.dll` |
| Linux | `linux/x64/libailia_ocr.so` |
| Android | `android/src/main/jniLibs/arm64-v8a/libailia_ocr.so` |

## macOS Download Attribute

If a security error occurs with a downloaded file on macOS, please execute the following command to remove the download attribute.

```
xattr -d com.apple.quarantine macos/libailia_ocr.dylib
```
